## Tentang

Repo ini menyimpan kode Java dari kelas Dasar Pemrograman semester 1 di Politeknik Negeri Malang, dari `Hello World` sampai nested loop. Tiap pertemuan punya satu folder berisi jobsheet, percobaan, dan tugas. Pertemuan 6, 8, dan 9 menyertakan laporan dengan kode, hasil, dan analisis.

| | |
| --- | --- |
| **Mata kuliah** | Dasar Pemrograman |
| **Kampus** | Politeknik Negeri Malang |
| **Bahasa** | Java 21 atau lebih baru |
| **Editor** | VS Code |

> [!NOTE]
> Nomor jobsheet berbeda dari nomor pertemuan. Jobsheet 7 jatuh di Pertemuan 8, dan Jobsheet 8 di Pertemuan 9.

## Jalankan Sendiri

Pasang JDK 21 atau lebih baru, lalu cek instalasinya:

```bash
java -version
javac -version
```

<details>
<summary><b>Compile lalu jalankan</b></summary>

```bash
cd "Pertemuan Kesembilan/2.1 Experiment 1"
javac Star18.java
java Star18
```

</details>

<details>
<summary><b>Jalankan dari source</b></summary>

JDK 11 ke atas menjalankan satu file `.java` tanpa langkah compile terpisah dan tanpa file `.class`:

```bash
java Star18.java
```

</details>

<details>
<summary><b>Pakai VS Code</b></summary>

Pasang Extension Pack for Java, buka folder repo, lalu klik **Run** di atas method `main`.

</details>

Program yang meminta input memakai `Scanner`, jadi ketik jawabanmu di terminal setelah program mulai.

## Aturan Penamaan

- Nama file sama dengan nama `public class` di dalamnya. `NamaKelas.java` berisi `public class NamaKelas`.
- Akhiran di belakang nama kelas menandai pekerjaan penulis.
