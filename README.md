## Tentang

Repo ini menyimpan kode Java dari kelas Dasar Pemrograman semester 1 di Politeknik Negeri Malang, dari `Hello World` sampai nested loop. Tiap pertemuan punya satu folder berisi jobsheet, percobaan, dan tugas. Pertemuan 6, 8, dan 9 menyertakan laporan dengan kode, hasil, dan analisis.

| | |
| --- | --- |
| **Mata kuliah** | Dasar Pemrograman |
| **Kampus** | Politeknik Negeri Malang, kelas TI-1I |
| **Dosen** | Pak Imam |
| **Bahasa** | Java 21 atau lebih baru |
| **Editor** | VS Code |

> [!NOTE]
> Nomor jobsheet berbeda dari nomor pertemuan. Jobsheet 7 jatuh di Pertemuan 8, dan Jobsheet 8 di Pertemuan 9.

## Mulai Cepat

Pasang JDK 21 atau lebih baru, lalu jalankan satu program:

```bash
java -version
git clone https://github.com/nxbiel/Pembelajaran-Java-Semester-1.git
cd Pembelajaran-Java-Semester-1/"Pertemuan Kesembilan/2.1 Experiment 1"
java Star18.java
```

JDK 11 ke atas menjalankan satu file `.java` tanpa langkah compile terpisah. Program yang meminta input memakai `Scanner`, jadi ketik jawabanmu di terminal setelah program mulai.

Di VS Code, pasang Extension Pack for Java, buka folder repo, lalu klik **Run** di atas method `main`.

## Aturan Penamaan

- Nama file sama dengan nama `public class` di dalamnya. `Star18.java` berisi `public class Star18`.
- Akhiran `18` adalah nomor presensi penulis. Program di Pertemuan 3 memakai akhiran `Nabil`.
